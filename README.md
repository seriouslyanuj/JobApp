## 📝 Job Application Portal – Spring Boot (Beginner Project)

This is my **first Spring Boot project** – a basic Job Application Portal built using **Spring Boot** and **JSP pages**. Instead of using a traditional database, I’ve used a simple **Java Array** to simulate backend storage for job applications.

### 🚀 Features
- Submit a job application with basic details (Name, Email, Position)
- View all submitted applications
- Basic server-side rendering using JSP
- MVC architecture with Spring Boot

### 🔧 Tech Stack
- Java
- Spring Boot
- JSP
- HTML/CSS (basic styling)
- No database – uses ArrayList to store data temporarily

### 📁 Folder Structure
```
src
└── main
    ├── java
    │   └── com.example.jobapp
    │       ├── controller
    │       ├── model
    │       └── service
    └── webapp
        └── WEB-INF
            └── views
```

### 📌 Note
This project is a beginner-friendly attempt to understand the basics of **Spring Boot**, **servlet communication**, and **JSP rendering**. No persistent storage has been used – data is lost once the server restarts.
